# Repositório de Estudos em Python 🐍

Olá! 👋 Este é o meu laboratório pessoal e o registro público da minha jornada com
Python — dos fundamentos até tópicos mais avançados. Aqui ficam códigos, anotações e
pequenos projetos que escrevo para praticar e fixar o que aprendo.

---

## 🎯 Objetivo

Construir uma base sólida em Python, dominar seus paradigmas (com destaque para a
Orientação a Objetos) e ser capaz de aplicar a linguagem na resolução de problemas reais —
de automações a aplicações completas. Este repositório é a fundação: a partir dele, o
código evolui para projetos maiores em repositórios próprios.

---

## 📂 Estrutura do Repositório

O conteúdo é dividido em **quatro níveis de complexidade**. Cada nível contém **pastas
numeradas por tópico** e, quando faz sentido, uma pasta **`exercicios/`** com desafios
práticos daquele nível.

```
estudos_python/
│
├── 01_basico/                      # Fundamentos da linguagem
│   ├── 01_variaveis_e_tipos_de_dados/
│   ├── 02_operadores/
│   ├── 03_estruturas_condicionais/
│   ├── 04_estruturas_de_repeticao/
│   ├── 05_listas_tuplas_dicionarios/
│   └── exercicios/                 # prática de lógica básica
│
├── 02_intermediario/               # Exige base sólida do nível anterior
│   ├── 01_funcoes_e_escopo/
│   ├── 02_regex/
│   ├── 03_orientacao_a_objetos/    # classes, abstratas, dataclass, metaclasses
│   ├── 04_tratamento_de_erros/     # (em construção) try/except/raise
│   ├── 05_arquivos_e_json/         # (em construção) leitura/escrita e persistência
│   └── exercicios/                 # sistemas pequenos, strings, pilhas e filas
│
├── 03_avancado/                    # Domínio mais profundo da linguagem
│   └── 01_decoradores/
│       # próximos: geradores/iteradores, type hints, ambiente virtual (venv)
│
└── 04_projetos/                    # Conhecimento aplicado em projetos completos
    ├── Gerador_de_Senhas_Seguras/
    └── app_motivacional_tkinter/
```

### O que vive em cada nível

- **🐍 `01_basico/`** — variáveis e tipos, operadores, condicionais, laços de repetição
  e estruturas de dados (listas, tuplas, dicionários).
- **🚀 `02_intermediario/`** — funções e escopo (incl. lambda), expressões regulares,
  Programação Orientada a Objetos, e (em construção) tratamento de erros e manipulação de
  arquivos/JSON.
- **🧠 `03_avancado/`** — recursos que exigem maturidade na linguagem: decoradores e, na
  sequência, geradores, type hints e boas práticas de ambiente.
- **🛠️ `04_projetos/`** — cada subpasta é um mini-projeto que junta vários conceitos.

## 🧭 Convenções do repositório

- **Um arquivo por conceito/exercício**, com nome descritivo em `snake_case`
  (ex.: `estruturas_condicionais.py`).
- **Pastas numeradas** para manter a ordem de aprendizado dentro de cada nível.
- **`exercicios/`** guarda a prática livre (desafios de fixação) de cada nível.
- Código escrito para **entender e explicar**, não só para funcionar — muitos arquivos
  trazem comentários do raciocínio.
- Arquivos temporários (como `__pycache__/`) são ignorados via `.gitignore`.
